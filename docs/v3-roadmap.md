## Инварианты безопасности

1. Восстановление запрещено при работающем Minecraft; блокировка запуска должна удерживаться на время замены мира.
2. Недоступность SSH — не доказательство остановки сервера.
3. Исходный ZIP сохраняется; перед заменой создаётся защитный ZIP текущего мира.
4. Путь из ZIP проверяется: запрещены выход из каталога, симлинки, специальные файлы и архивы без `level.dat`.
5. Если файловая система не поддерживает `renameat2(RENAME_EXCHANGE)`, восстановление прерывается без замены мира.

## Про systemd

Minecraft-серверы запускаются ботом напрямую через настроенный `start_command` (локально или через SSH). Отдельный systemd-unit Minecraft для этого не требуется. Файл `deploy/systemd/telegram-minecraft-server-manager.service` — **необязательный** пример запуска самого Telegram-бота, а не Minecraft.
