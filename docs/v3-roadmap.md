## Гарантии и ограничения восстановления

1. Восстановление мира допускается только при остановленном Minecraft. Запуск блокируется на время замены.
2. Недоступность SSH не означает, что сервер остановлен.
3. Исходный ZIP сохраняется, перед заменой создаётся отдельный защитный архив.
4. Не допускаются ZIP с обходом путей, симлинками, специальными файлами или без `level.dat`.
5. Если `renameat2(RENAME_EXCHANGE)` не поддерживается, операция прерывается без замены мира.

## systemd

Minecraft управляется ботом напрямую через `start_command` либо через SSH. Отдельный сервис systemd для Minecraft **не требуется**. `deploy/systemd/telegram-minecraft-server-manager.service` — необязательный пример запуска самого Telegram-бота.
